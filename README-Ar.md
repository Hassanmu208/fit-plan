# مصدر FitPlan المنظّم

هذه نسخة مصدر مرتبة لتسهيل صيانة التطبيق وتقليل أخطاء التعديل. ملف التشغيل الحالي `outputs/fitplan.html` لم يُستبدل أو يُعدّل.

## المجلدات

- `src/shell.html`: هيكل صفحة HTML ومواقع إدراج الملفات.
- `src/styles/`: كتل CSS بالترتيب الذي تستخدمه الصفحة.
- `src/scripts/`: كتل JavaScript بالترتيب الذي تستخدمه الصفحة.
- `src/assets/`: الصور الكبيرة التي كانت مضمنة بصيغة Base64 داخل CSS أو JavaScript.
- `manifest.json`: ترتيب تحميل كل كتلة ومكانها في الصفحة.
- `build.ps1`: يعيد تجميع الملفات في صفحة HTML واحدة مستقلة.
- `preview/fitplan.html`: النسخة الناتجة للمعاينة أو الرفع.

## قواعد مهمة لتجنب كسر التطبيق

1. لا تغيّر ترتيب الكتل في `manifest.json`؛ بعض الملفات تعتمد على تعريفات سابقة، وبعض التعريفات اللاحقة تستبدل تعريفات أقدم عمدًا.
2. لا تحذف الدوال المتكررة لمجرد تكرار اسمها. راجع مواضع الاستخدام أولًا، لأن ترتيبها الحالي قد يغيّر السلوك.
3. لا تحذف ملفات الصور في `src/assets/` ولا تغيّر أسماءها؛ أداة التجميع تعيد تضمينها داخل HTML النهائي.
4. عدّل ملفات `src/`، ثم شغّل `build.ps1`. الملف الناتج يظل صفحة HTML واحدة، مثل النسخة الحالية.
5. الناتج يذهب إلى `preview/fitplan.html`، ولا يستبدل `outputs/fitplan.html` تلقائيًا.

## إنشاء نسخة HTML

افتح PowerShell داخل هذا المجلد وشغّل:

```powershell
.\build.ps1
```

بعد التأكد من المعاينة، يمكن استخدام `preview/fitplan.html` عند تحديث نسخة الموقع.
